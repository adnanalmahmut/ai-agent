# Task brief

Use this contract for substantial work. Omit a field only when it is genuinely
irrelevant; do not turn routine one-file changes into ceremony.

## Goal

The concrete outcome to achieve.

## Context

Why the work matters, current behavior, and evidence already known.

## Scope

Files, systems, users, or behaviors included.

## Non-goals

Adjacent work explicitly excluded.

## Constraints

Security, compatibility, deployment, time, dependency, and authority limits.

## Acceptance criteria

Observable conditions that define completion.

## Validation

Commands and scenarios that must pass.

## Required evidence

Diffs, test output, screenshots, logs, documentation, or PR checks required for
review. Never include secret values or live environment dumps.

## Git / PR policy

Base/head, commit or PR structure, publication authority, and forbidden Git or
deployment actions.
